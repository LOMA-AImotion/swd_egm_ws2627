# SWD – Engineering and Management (EGM), Winter Semester 2026/27

Welcome, 3rd-semester **Engineering and Management** students at
**Technische Hochschule Ingolstadt (THI)**!

This repository contains all the code written live during our lectures.
After each session, the examples are pushed here, so you'll always find
everything we covered in one place.

## Structure

Each lecture has its own folder:

```
lecture2/   # loops, conditionals, ranges, ...
...
```

## Getting started

Clone the repository once:

```bash
git clone https://github.com/LOMA-AImotion/swd_egm_ws2627.git
```

and pull the latest lecture code before each session:

```bash
git pull
```

Run any example with Python, e.g.:

```bash
python lecture2/even_numbers.py
```

Feel free to experiment with the code. Changing things and breaking them
is the best way to learn!
